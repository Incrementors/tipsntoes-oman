# Tips'NToes Oman website concept

Static design concept for Tips'NToes Oman (four nail and beauty lounges in Muscat and Sohar). Served from GitHub Pages at `/tipsntoes-oman/` (Settings → Pages → Deploy from branch → `main` / root).

## Pages

| Template | URL |
| --- | --- |
| Home | `/tipsntoes-oman/` |
| Lounge | `/tipsntoes-oman/lounges/muscat-grand-mall/` (and the other three) |
| Treatment | `/tipsntoes-oman/treatments/manicure-pedicure/`, `/tipsntoes-oman/treatments/nail-extensions/` |
| Site plan | `/tipsntoes-oman/site-plan/` |

Any other link opens `planned/`, which shows the address that page will use on tipsntoesoman.com (`404.html` redirects there).

## Features

- Booking card on every page (demo modal), and a chat-to-book option.
- English / Arabic switch (right to left) in the header.
- "Strategy notes" switch in the top bar explains why each section is built the way it is.
- LocalBusiness, Organization and FAQ structured data on every page.

Photos load from their Unsplash originals and stand in for a lounge photo shoot. All pages are `noindex, nofollow` and robots.txt blocks crawling while this is a staging concept.
